Memory+ / 忆家 · 老人端 iPad 5.0（最新版）

包含中英文切换、点击/手势训练、家庭客厅、我的家 3D 生活任务、生活动作练习。
已包含训练页面的紧凑布局更新，六张点击训练卡可在 iPad 横屏一屏完整显示。

一、上传网站
ZIP 根目录已放置 index.html，无须构建。
上传或解压包内全部文件，保留原目录结构。
部署目录应直接包含 index.html，不要再套一层 dist 或项目文件夹。
需使用 HTTPS 网站，才能开启摄像头识别手势。
手势识别模型和主要静态素材已包含在包内。

二、电脑本机预览
不要直接双击 index.html：浏览器会限制 JavaScript 模块，可能出现空白。
请在解压目录运行：python3 -m http.server 8000
然后访问：http://localhost:8000/
Windows 已安装 Python 时可双击 Start-Windows.bat。

三、iPad 体验
推荐横屏使用 Safari，打开部署后的 HTTPS 网站地址。
首页和设置可切换中英文。
训练页右上角可选择点击或手势模式；选择手势项目后开启摄像头。
首次使用时允许摄像头访问，并保持手部处于镜头内。
进入家庭客厅，可选择相册、我的家及生活动作练习。

四、演示说明
此包为交互原型，部分任务、报告和家庭数据采用演示数据。
本机设置保存在当前浏览器，不会自动与其他设备同步。
语音播报需设备提供相应的中文或英文系统语音。
