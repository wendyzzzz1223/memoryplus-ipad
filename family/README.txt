Memory+ / 忆家 · 子女端：语音设置交互演示

一、上传网站
本压缩包根目录就是网站目录，index.html 已放在根目录。
上传解压后的全部文件，并保留 assets、figma-assets 文件夹。
如果托管平台支持直接上传 ZIP，可直接选择本压缩包。
如果平台需要输出目录，请选择包含 index.html 的目录。
这是静态网页，不需要 npm 安装或构建。

二、本机打开
解压后可以用浏览器打开 index.html。
如果浏览器限制本地网页，请在此目录启动静态服务器：
python3 -m http.server 8000
然后访问 http://localhost:8000/ 。
Windows 已安装 Python 时，可双击 Start-Windows.bat。

三、演示路径
首页登录页选择“直接体验王建国家庭” → 我的 → 家人语音录制。
也可以在网站地址后添加 #voice，直接进入语音设置。

四、新增语音交互
选择女儿或儿子声音 → 模拟录制声音 → 开始模拟录音。
录音展示动态波形、计时，12 秒自动结束，也可手动结束。
点击“开始 AI 学习”，展示进度与分阶段反馈。
完成后提示“声音设置成功”，对应声音显示“使用中”。
支持重新录制、取消、试听示例以及切换使用声音。
选择状态保存在当前浏览器，刷新后保留。

五、演示范围
录音和 AI 学习均为模拟交互，不请求麦克风、不采集或上传声音。
试听采用设备系统语音，并非家人真实声音或 AI 复刻声音。
试听需设备具有可用的中文系统语音。
数据仅在当前浏览器保存，不会同步至长辈设备或其他浏览器。
